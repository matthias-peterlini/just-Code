IDE di codice AI per il terminale. Un modello orchestratore divide il lavoro in compiti piccoli; i sub-agenti li eseguono in parallelo sul tuo progetto.

npm install -g @justapps/just-code

macOS, Linux e Windows · Node.js 20 o successivo · altri metodi in installazione

NOME

  
just-code — assistente di programmazione a più agenti, per il terminale.






  
SINTASSI

  

    just-code [--turbo] [--orchestrator provider:modello] [--sub provider:modello] [--parallel n] [richiesta]
  






  
DESCRIZIONE

  

    
Avvia just-code nella cartella del progetto e scrivi cosa vuoi ottenere. La richiesta va all'orchestratore, di solito un modello grande come Gemini 2.5 Pro. L'orchestratore legge il codice quanto basta per capire il problema, poi chiama lo strumento spawn_agents con un elenco di compiti.



  richiesta ──▶ orchestratore ──┬──▶ explorer    ──┐
                gemini-2.5-pro  ├──▶ bug-fixer   ──┤
                                ├──▶ test-writer ──┼──▶ orchestratore ──▶ risposta
                                └──▶ docs        ──┘    verifica

    
    
      
  1. Ogni sub-agente parte senza la conversazione: riceve solo il compito scritto dall'orchestratore, con i percorsi dei file e il risultato atteso. Il contesto resta piccolo, quindi per gli agenti basta un modello veloce ed economico.
    2. 
      
  2. Gli agenti lavorano in parallelo, al massimo /parallel alla volta (4 di default); gli altri aspettano in coda.
    3. 
      
  3. Ogni agente chiude con un breve rapporto: cosa ha fatto, quali file ha toccato, cosa resta aperto. L'orchestratore controlla i rapporti, se serve lancia un altro giro e poi risponde.
    4. 
      
  4. Le domande semplici ricevono risposta diretta, senza agenti.
    5. 
    

  






  
STRUMENTI

  

    

      
strumentocosa faconferma

      
read_filelegge un file, con numeri di rigano

      
list_fileselenca i file, con filtro globno

      
searchcerca un'espressione regolare nei fileno

      
write_filecrea o sovrascrive un filesì

      
edit_filesostituisce un pezzo di testo esattosì

      
run_shellesegue un comando (timeout 120 s)sì

    

    
Gli strumenti non escono dalla cartella da cui hai avviato just-code. node_modules, .git e dist vengono ignorati nelle ricerche.

  






  
PERMESSIe turbo

  

    
Prima di scrivere un file o eseguire un comando, l'agente si ferma e mostra cosa vuole fare. Rispondi con y (sì), a (sempre, per questo strumento), n (no) oppure t.

    
t attiva la modalità turbo: da quel momento gli agenti agiscono senza chiedere. Si attiva anche con /turbo o avviando just-code --turbo, e si spegne con /turbo.

  





  
richiesta di permessopremi t

  








  
PROVIDER

  

    
Orchestratore e sub-agenti possono usare provider diversi. Il modello si scrive provider:modello.

    

      
provideraccessoesempio

      
gemini/login con account Google, oppure GEMINI_API_KEYgemini:gemini-2.5-pro

      
groqGROQ_API_KEYgroq:llama-3.3-70b-versatile

      
openrouterOPENROUTER_API_KEYopenrouter:deepseek/deepseek-chat

      
openaiOPENAI_API_KEYopenai:gpt-4.1-mini

      
customqualsiasi API compatibile OpenAI: Ollama, LM Studio, vLLMcustom:llama3.1

    

    
Esempio: pianificare con Gemini ed eseguire su Groq.


/model orchestrator gemini:gemini-2.5-pro
/model sub groq:llama-3.3-70b-versatile
/key groq gsk_…

    
L'orchestratore può anche scegliere un modello diverso per un singolo agente.

  






  
ACCESSOGoogle

  

    
Con /login si apre il browser e accedi con il tuo account Google, senza copiare chiavi. just-Code riceve un token per Gemini, lo salva in ~/.just-code/ e lo rinnova da solo. /logout lo cancella.

INSTALLAZIONE

  

    
CON NPM (macOS, Linux, Windows · Node.js 20+)


npm install -g @justapps/just-code

    
macOS / LINUX


curl -fsSL https://code.justapps.it/install.sh | sh

    
WINDOWS (PowerShell)


irm https://code.justapps.it/install.ps1 | iex

    
AVVIO


cd il-tuo-progetto
just-code              # oppure: jc
/login                 # Gemini con account Google

    
Gli script controllano che ci sia Node.js 20+ e installano il pacchetto da npm; se npm non risponde usano l'ultima release su GitHub (code.justapps.it/latest.tgz). Per aggiornare: npm update -g @justapps/just-code.
