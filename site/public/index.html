IDE AI per il terminale · open source

Un orchestratore.
Tanti agenti.

just-Code è un IDE di codice nel terminale. Un modello orchestratore (Gemini, Groq, OpenRouter o qualsiasi API) capisce cosa vuoi, divide il lavoro in piccoli compiti e lo assegna a sub-agenti che lavorano in parallelo sul tuo progetto.

Inizia ora → GitHub
$ npm install && npm run build && npm link && just-code
~/progetti/my-app — just-code
Come funziona

Pensa uno, lavorano in tanti.

Invece di un solo modello che fa tutto in fila, just-Code usa un modello potente come regista e tanti modelli veloci come esecutori. Il lavoro indipendente procede in parallelo, così i task grandi finiscono prima.

Funzioni

Tutto quello che serve, dentro al terminale.

⇶

Sub-agenti in parallelo

Fino a 32 agenti insieme (regolabile con /parallel), con stato, tempi e numero di strumenti usati sempre visibili.

⚙

Strumenti veri

Ogni agente può leggere, cercare, creare e modificare file ed eseguire comandi shell: test, build, git, npm…

⇄

Modelli misti

Un modello potente per pianificare, modelli rapidi ed economici per eseguire. Puoi scegliere anche il modello del singolo agente.

G

Login con Google

Per Gemini non serve una API key: /login apre il browser, accedi con il tuo account Google e il token si rinnova da solo.

🔒

Permessi chiari

Prima di scrivere file o eseguire comandi ti mostra cosa vuole fare. Puoi rispondere sì, sempre, no o attivare TURBO.

✦

UI animata

Logo animato, pannello live degli agenti con barra di avanzamento, autocompletamento dei comandi / e Markdown nel terminale.

Provider

Usa il modello che vuoi.

Gemini con l'API nativa, più qualsiasi servizio compatibile con le API di OpenAI. Il formato è sempre provider:modello.

Google Geminigemini:gemini-2.5-pro
Groqgroq:llama-3.3-70b-versatile
OpenRouteropenrouter:deepseek/deepseek-chat
OpenAIopenai:gpt-4.1-mini
Qualsiasi APIcustom:llama3.1 (Ollama, LM Studio, vLLM…)
# l'orchestratore pianifica con Gemini, gli agenti eseguono su Groq
/model orchestrator gemini:gemini-2.5-pro
/model sub groq:llama-3.3-70b-versatile
/key groq gsk_••••••••
/baseurl custom http://localhost:11434/v1
Modalità Turbo

Quando ti fidi, vai a tutta.

Di default just-Code chiede conferma prima di ogni azione che modifica il progetto. In TURBO gli agenti scrivono file ed eseguono comandi senza fermarsi, e l'attivazione arriva con un'esplosione di colori.

? Permission agent test-writer wants to run_shell
$ npm test
[y] yes [a] always [n] no [t] TURBO ⚡
TURBO
/turbo · tasto t · just-code --turbo
Installa

Pronto in un minuto.

Serve Node.js 20 o più recente e un terminale con colori truecolor (Windows Terminal, iTerm2, Ghostty, Kitty, terminale di VS Code…).

# scarica e compila
git clone https://github.com/matthias-peterlini/just-code
cd just-code
npm install && npm run build && npm link

# avvialo nella cartella del tuo progetto
cd ~/progetti/my-app
just-code

# dentro just-Code
/login          # accedi con Google → Gemini pronto

Senza login puoi usare una chiave: export GEMINI_API_KEY=…, GROQ_API_KEY, OPENROUTER_API_KEY, OPENAI_API_KEY, oppure /key.

Comandi

Tutto con uno slash.

/login · /logoutAccount Google per Gemini
/modelScegli il modello dell'orchestratore o dei sub-agenti
/modelsModelli suggeriti per ogni provider
/key · /baseurlAPI key ed endpoint personalizzati
/parallel <n>Quanti sub-agenti possono lavorare insieme
/turboAttiva o disattiva TURBO
/status · /clearConfigurazione · nuova conversazione
